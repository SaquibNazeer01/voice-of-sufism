# 🕊️ Voice of Sufism (صداۓ تصوف)

> **A Perpetual Digital Sanctuary Preserving Kashmir's Living Sufi Heritage, Sacred Shrines, Reshi Philosophy & Mystical Poetry.**

Officially recognized and registered under the **Ministry of Micro, Small and Medium Enterprises (MSME), Government of India** (Reg. No: `UDYAM-JK-11-0013563`).

---

## 🌟 Overview

**Voice of Sufism** is an open-access, community-led digital archive dedicated to documenting, translating, and preserving centuries of Kashmiri spiritual literature, vernacular timber architecture, and oral folklore.

From the 14th-century verses of **Lal Ded** (*Vakhs*) and **Hazrat Sheikh Noor-ud-Din Noorani (Nund Reshi)** (*Shruks*), to the historic craft renaissance brought by **Mir Sayyid Ali Hamadani (Shah-e-Hamadan)** and his 700 artisans, Voice of Sufism serves as a repository for researchers, pilgrims, scholars, and future generations.

---

## 🏛️ Key Features

- **Sufi Saints & Reshi Masters Directory:** Chronological, in-depth biographical archives of Kashmir's spiritual guides (Kubrawi, Suhrawardi, Reshi, and Qadiri traditions).
- **Featured Ziyarats & Sacred Architecture:** Architectural breakdowns, historical origins, Urs traditions, and direct Google Maps GPS navigation for Kashmir's iconic shrines (Charar-i-Sharief, Khanqah-e-Moula, Dargah Hazratbal, Aishmuqam, Makhdoom Sahib, and Jamia Masjid).
- **Poetry Treasury (Vakhs & Shruks):** Original Kashmiri Nastaliq script, phonetic English transliterations, and spiritual translations.
- **Archival Photo Gallery:** High-resolution photographs capturing vernacular Kashmiri timber craftsmanship, Khatamband ceilings, and shrines across all seasons.
- **Voice of Sufism Assistant:** An interactive conversational knowledge agent trained on all platform chronicles, visitor etiquette, and leadership details.
- **Reading Modes & Offline Bookmarks:** Dynamic Ivory, Sepia, and Dark reading modes with adjustable typography scaling and localStorage persistence.
- **Administrative CMS Suite:** Secured administrative panel for editorial reviews, content publishing, and analytics.

## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/SaquibNazeer01/voice-of-sufism.git
cd voice-of-sufism

# Install dependencies
npm install

# Start local development server
npm run dev
```
Visit `http://localhost:3000` in your browser.

---

## 📦 Production Build & Deployment

```bash
# Run type checks and generate production bundle
npm run build

# Preview production build locally
npm run preview
```

### Environment Variables
Copy `.env.example` to `.env` and fill in your free Firebase credentials:
```env
VITE_FIREBASE_API_KEY="your-api-key"
VITE_FIREBASE_AUTH_DOMAIN="your-app.firebaseapp.com"
VITE_FIREBASE_PROJECT_ID="your-project-id"
VITE_FIREBASE_STORAGE_BUCKET="your-app.firebasestorage.app"
VITE_FIREBASE_MESSAGING_SENDER_ID="your-sender-id"
VITE_FIREBASE_APP_ID="your-app-id"
```
